# StudyTint

Kotlin + Jetpack Compose study app (Python, Maths, Exploration in AI, DBMS).

## Get the APK from GitHub
1. Create a new GitHub repo and push the contents of this folder to its root.
2. Open the **Actions** tab, choose **Build APK** (it also runs on every push).
3. When the run finishes, download **StudyTint-debug-apk** from the run's *Artifacts*.
4. If a build fails, download **build-logs** (`build.log`, `errors.log`, Gradle reports).
